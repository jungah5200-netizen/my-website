# 사이ON M40 · WE 우리의 이야기 첫 화면

M39의 로그인·온디·YOU 기능 유지, WE 탭 첫 화면 신설.

- 2026년 11월 샘플 피드 3개 (발표 응원 / 식탁 이야기 / 산책길의 가을)
- 6개 감정등 누르면 해당 감정별 필터 (다시 누르면 전체)
- 검색: 사람 / 이야기 / 날짜
- 기록 필터: 전체·글·사진·음성 및 기간
- 카드 클릭: 간단 상세 보기
- 책갈피: 브라우저에 저장되는 샘플 기억 담기
- 기억 묶음 만들기: 이름/선택된 샘플 게시물 ID를 브라우저에 저장
- 9:16 프레임과 기존 공통 하단 네비 재사용, 이중 네비 없음

주의: 샘플 피드는 가상의 시연 자료이며 아직 실제 지인의 서버 글을 불러오지 않습니다. 엄마 목소리는 실제 원본이 없으므로 상세에서 시연용 TTS로만 구분하여 사용합니다. 개인 감정 기록과 온디 대화는 WE에 공유하지 않습니다.
