# M37 로그인 화면 정지 오류 수정

원인: M35/M36에서 예전 화면별 하단 네비를 제거하면서 `id="youFooterCurrent"` 버튼도 삭제됐지만, `app.js`에 이 버튼의 `addEventListener` 호출이 남아 있었습니다. 존재하지 않는 요소에 이벤트를 등록하려고 `TypeError`가 발생해 초기화가 중단될 수 있었습니다.

수정: 해당 버튼 리스너에 optional chaining을 적용해 버튼이 존재하는 경우에만 등록하도록 수정했습니다. 전역 하단 네비게이션은 그대로 유지합니다.

테스트: Chromium에서 HTML/CSS/JS를 주입하는 방식으로 로그인 → 홈 → 온디 → YOU 클릭 전환 확인, 페이지 오류 0건, YOU 화면의 네비게이션 1개 확인. (로컬 HTTP URL 직접 이동 테스트는 실행 환경의 보안 정책상 제한됨.)

기존 기능/저장 데이터 구조 변경 없음.
