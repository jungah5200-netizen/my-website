# M30 받은 마음 상세

M29 기반. YOU 너에게 → 받은 마음 보기 → 민서 / 수아 / 민수 카드를 누르면 받은 마음 상세 화면이 표시됩니다.

- 카드별 감정등, 받은 날짜, 메시지, 배경 그림 표시
- 민서: 요청 이미지의 분홍 튤립 카드 배경 사용
- 민서·수아: '시연용 읽어주기' 버튼은 브라우저 TTS입니다. 실제 친구 녹음 원본이 아닙니다.
- 민수: 사진만 표시하며 음성 재생 칸을 숨깁니다.
- 마음 담기: 이 브라우저 localStorage로 저장, 다시 누르면 취소
- 답장하기: 친구 이름을 수신자로 지정해 기존 마음 보내기 플로우로 이동
- 기존 9:16 프레임, 하단 내비게이션 유지

주의: 실제 친구 메시지 수신/서버 동기화는 미구현입니다. 모든 받은 메시지는 시연용 샘플입니다.

검사: JavaScript 문법과 화면별 필수 요소/이미지 경로를 검사했습니다. 자동화 브라우저 접근은 이 실행환경에서 차단되어 실제 클릭 테스트는 미완료입니다.
