# 사이ON M28 — YOU 너에게 기능 확장

M27을 기준으로 작업했습니다. 기존 로그인, 온미·온룸, 감정 기록, 온디 채팅, 기분 체크, YOU 내역 및 하단 네비게이션을 유지합니다.

## YOU 마음 보내기
1. 하단 YOU 너에게 → 새 마음이 도착했어요! → 상단 보내기
2. 받는 사람 선택: 기본 민서·엄마·민수, 추가 버튼으로 가족·친구 등 이름 및 관계 등록
3. 마음카드 배경 4종: 튤립·노을 하늘·책과 머그컵·잠든 고양이. 새로 만든 일러스트 4장을 웹 이미지 자산으로 제공
4. 카드 글 입력(최대 120자)
5. 실제 마이크 녹음/종료/미리 듣기 또는 녹음 파일 선택, 음성 없이 다음도 가능
6. 홈과 동일한 감정등 6개를 가로로 선택, 확인 버튼
7. 사용자가 제공한 ‘민서에게 마음을 보냈어요!’ 원본 완료 화면 → 마음 목록으로
8. 보낸 마음 목록에 방금 보낸 카드가 표시되고, 눌러서 카드와 음성을 재확인할 수 있음

## 저장 방식
- 상대방에게 실제로 메시지를 전송하지 않습니다. 오프라인 웹 프로토타입입니다.
- 받는 사람 목록 및 보낸 카드(글·감정·배경·시간)는 브라우저 localStorage에 저장합니다.
- 녹음 음성의 실제 Blob은 같은 브라우저의 IndexedDB에 저장합니다. 브라우저 데이터 삭제/시크릿 모드에서는 기록이 사라질 수 있습니다.
- `getUserMedia` 마이크 녹음은 **HTTPS 또는 http://localhost** 와 같은 안전한 출처에서만 사용할 수 있습니다. 같은 LAN의 `http://192.168.x.x` 주소로 접속하면 Chrome 정책으로 마이크 기능이 차단될 수 있습니다. 이 경우 HTTPS로 배포하거나 localhost에서 실행하세요. 파일 업로드는 대안으로 제공합니다.

## 실행
압축 해제 후 폴더 루트에서 로컬 개발 서버를 실행하고 index.html을 엽니다.
예: `python -m http.server 3000` 후 `http://localhost:3000/` (일부 브라우저는 file:// 실행 시 저장/마이크 제한)

## 검증
- JS 구문 검사, 필요한 DOM ID와 파일 참조, PNG/WebP 자산, ZIP 파일 검사를 완료했습니다.
- 현재 실행 환경의 브라우저 네트워크 접근은 관리자 정책에 의해 차단되어 실제 클릭·스크롤·마이크 테스트는 완료하지 못했습니다.


## M29 — 감정등 중심 주고받은 마음 목록
- YOU 탭 → 받은 마음 보기 → 목록 화면
- 원본 시안의 상단 및 하단 디자인 유지, 가운데만 실제 HTML 카드 목록으로 변경
- 각 카드 왼쪽에 홈과 동일한 감정등, 가운데 이름/시간/감정/내용, 오른쪽 글/음성/사진 아이콘
- 날짜별 그룹화 및 전체/글/음성/사진 필터 지원
- M28에서 새로 보낸 마음카드도 같은 목록에 추가, 클릭하면 카드/음성 상세 확인
- 기존 데모 받은 메시지 3개는 설명용 고정 항목입니다. 서버 수신은 아직 지원하지 않습니다.

테스트: JS 문법 검사 및 HTML 요소 참조 검사 완료. 이 환경에서는 브라우저 접근이 차단되어 실제 클릭 자동화 테스트는 수행하지 못했습니다.
