# 사이ON M42 — WE 우리 검색 / 상세 달력 필터

- M41 전체 기능 유지. WE > 기록 필터 내 **기록 유형**을 **우리 검색**으로 교체.
- 관계 분류: 엄마와 나 / 민수♥나(남자친구) / 절친.
- 각 관계별 시연 피드 3개씩, 총 9개. 모두 예시이며 실제 사용자의 데이터가 아님.
- WE 메인 피드에서 시작일·종료일을 브라우저 기본 달력으로 지정하고 기간 적용/전체 기간 초기화 가능.
- 기억 묶음의 기록 고르기에서도 시작일·종료일로 필터링 가능.
- 날짜 범위는 양 끝 날짜 모두 포함. 시작일이 종료일보다 늦으면 적용되지 않음.
- 선택한 기록만 브라우저 localStorage에 기억 묶음으로 보관. 개인 감정/온디 대화 자동 공유 안 함.
- 음성 예시는 실제 녹음이 아닌 시연용 대화 텍스트와 브라우저 TTS.
